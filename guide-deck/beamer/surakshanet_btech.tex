% ==================================================================
% 10 — DIVIDER II
% ==================================================================
\setpart{Part II --- Method}
\partdivider{II}{Method}{Turning Devanagari Hindi into Hinglish without inventing new labels.}
{\textbf{Can't we just respell it in Roman letters?} We tried and measured it: respelling changes the script, not the language.}
{\textbf{So how do we get Hinglish?} An LLM rewrites each message once, offline. It never runs inside the extension.}
{\textbf{How do we know the rewrite is still abusive?} A two-part gate keeps or quarantines each rewrite. Part IV measures how well it does that.}
